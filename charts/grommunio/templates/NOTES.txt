The first start takes several minutes (database initialisation, certificate
installation, Files installation). Follow it with:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w
  kubectl -n {{ .Release.Namespace }} logs -f {{ $fullname }}-core-0

1. DNS
{{- if .Values.service.core.externalIPs }}
   Point {{ .Values.grommunio.fqdn }} and autodiscover.{{ .Values.grommunio.domain }} (A/AAAA) and the MX of
   {{ .Values.grommunio.domain }} at: {{ join ", " .Values.service.core.externalIPs }}
{{- else if eq .Values.service.core.type "LoadBalancer" }}
   Point {{ .Values.grommunio.fqdn }} and autodiscover.{{ .Values.grommunio.domain }} (A/AAAA) and the MX of
   {{ .Values.grommunio.domain }} at the load balancer address:
     kubectl -n {{ .Release.Namespace }} get svc {{ $fullname }}-core -o jsonpath='{.status.loadBalancer.ingress[0].ip}{.status.loadBalancer.ingress[0].hostname}'
{{- else }}
   Service {{ $fullname }}-core is of type {{ .Values.service.core.type }}; publish its ports on your edge yourself.
{{- end }}
{{- if .Values.ingress.enabled }}
   HTTP(S) is served through the Ingress ({{ .Values.grommunio.fqdn }}); mail ports stay on the Service above.
{{- end }}

2. Admin UI (user "admin")
{{- if .Values.ingress.admin.enabled }}
   https://{{ .Values.ingress.admin.host }}/
{{- else if .Values.service.core.ports.admin.enabled }}
   https://{{ .Values.grommunio.fqdn }}:{{ .Values.service.core.ports.admin.port }}/
{{- else if ne .Values.service.admin.type "ClusterIP" }}
   https://<address of service {{ $fullname }}-core-admin>:{{ .Values.service.admin.port }}/
{{- else }}
   The admin UI is not exposed. Reach it with a port-forward:
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }}-core-admin 8443:{{ .Values.service.admin.port }}
   then open https://localhost:8443/ (or set service.admin.type / ingress.admin.*).
{{- end }}
   Password:
     kubectl -n {{ .Release.Namespace }} get secret {{ include "grommunio.secretName" . }} -o jsonpath='{.data.ADMIN_PASS}' | base64 -d; echo
   Webmail: https://{{ .Values.grommunio.fqdn }}/  (create a domain and users in the admin UI first)

3. TLS ({{ .Values.tls.mode }})
{{- if eq .Values.tls.mode "selfSigned" }}
   The certificate is issued by a CA generated by this chart. Install the CA on
   your clients, or switch to tls.mode=certManager / existingSecret:
     kubectl -n {{ .Release.Namespace }} get secret {{ include "grommunio.caSecretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > grommunio-ca.crt
   With `helm template` / GitOps renderers the chart cannot look up the stored CA and
   issues a new one on every render: use tls.mode=certManager or existingSecret there.
{{- else if eq .Values.tls.mode "certManager" }}
   cert-manager Certificate {{ $fullname }}-tls -> Secret {{ include "grommunio.tlsSecretName" . }} (issuer {{ .Values.tls.certManager.issuerRef.kind }}/{{ .Values.tls.certManager.issuerRef.name }}).
   Rotations are picked up inside the pods without a restart.
{{- else }}
   Using Secret {{ include "grommunio.tlsSecretName" . }}. Rotations are picked up inside the pods without a restart.
{{- end }}

{{- if and (eq .Values.network.hairpin.mode "hostAliases") (not .Values.service.internal.clusterIP) }}

4. Hairpin (archive/office -> https://{{ .Values.grommunio.fqdn }})
   The pods resolve the internal Service at start. To make this independent of
   DNS timing, pin the ClusterIP in your values and upgrade:
     kubectl -n {{ .Release.Namespace }} get svc {{ $fullname }}-core-internal -o jsonpath='{.spec.clusterIP}'
   -> service.internal.clusterIP: "<that address>"
{{- end }}

{{- if .Values.features.archive.enabled }}

5. BACK UP THE ARCHIVE ENCRYPTION KEY NOW. Without it archived mail is unreadable:
     kubectl -n {{ .Release.Namespace }} exec {{ $fullname }}-archive-0 -- cat /var/lib/grommunio-archive/grommunio-archive.key > grommunio-archive.key
   (store it with the Secrets {{ include "grommunio.secretName" . }}{{ if .Values.mariadb.enabled }} and {{ include "grommunio.rootSecretName" . }}{{ end }}; all carry helm.sh/resource-policy: keep)
{{- end }}

data, Secrets and PVCs in place. See the chart README for upgrades, backups,
migration from docker-compose and the security model.
